BrainPlizz

Многопользовательская веб-игра-викторина в режиме реального времени.

***О проекте***

BrainPlizz — учебный дипломный проект, представляющий собой многопользовательскую веб-игру, в которой несколько игроков могут одновременно участвовать в одной викторине.

Игроки подключаются к игровой комнате, отвечают на вопросы в режиме реального времени и соревнуются за лучший результат.

***Планируемый стек***

***Backend***
- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- WebSocket
- JWT

***Frontend***
- React
- JavaScript / TypeScript
- HTML
- CSS

***Инфраструктура***
- Docker
- Docker Compose
- Git / GitHub

***Основные возможности***

- регистрация и авторизация пользователей;
- создание игровой комнаты;
- подключение нескольких игроков;
- проведение викторины в режиме реального времени;
- таймер вопросов;
- проверка ответов;
- подсчёт баллов;
- рейтинг игроков;
- итоговые результаты;
- управление вопросами.
